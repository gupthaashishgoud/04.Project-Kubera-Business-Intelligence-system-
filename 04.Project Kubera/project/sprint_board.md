## Definition of Done

- [ ] Code reviewed and merged to `main`
- [ ] Unit tests pass (>80% coverage)
- [ ] ML model validation AUC-ROC > 0.90
- [ ] Bias audit passed (demographic parity < 0.05)
- [ ] QA sign-off on Chrome, Firefox, Safari, Mobile
- [ ] Accessibility audit passed (WCAG AA)
- [ ] Data accuracy verified against core banking system
- [ ] PM sign-off on UI/UX match to Figma
- [ ] AI explanations approved by compliance team
- [ ] Deployed to staging and smoke-tested
